1. Menu bar is TopBar.jsx (src/components/TopBar.jsx, master 20a60290). There is no legacy MenuBar component; the eleven menus in prod are File, Edit, View, Modeling, Projector, Lighting, Tools, Appearance, Share, Settings, Help. Facts the writer should get right:

The File menu hint only says '.fbx .glb .obj' but the picker and loaders accept all seven. .blend, .skp, .3ds, .max are refused with a toast that names the export path. Size cap 200 MB, warning plus confirm at 100 MB. There is NO drag-and-drop of OS files onto the 3D viewport (MediaDropCatcher ignores OS drags); drag-and-drop works only inside the Import Floor Plan overlay.
- Units on model import are auto-detected (file metadata for FBX/GLB/glTF/DAE; '# Units:' comment or bounding-box heuristic for OBJ; bbox for STL/PLY). The 'Import Unit' modal exists in code but is never opened, and the 'Source unit' row in the Inspector is a read-only badge; several toasts mention a 'Source Unit dropdown' that does not exist. Do not advertise a manual unit override.

A CAD import becomes locked 'reference lines'; walls are built by selecting lines, 'Trace selected → my sketch', then W (raise walls).
