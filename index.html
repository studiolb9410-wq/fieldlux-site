Stress analysis

Not AI judgment. Engineering checks you can inspect.

FieldLux tests how a projection setup reacts when site conditions move: throw distance, ambient lux, lens shift, coverage, overlap, pixel density, and output margin. The point is not a black-box answer. The point is knowing where the setup is fragile before installation day.
